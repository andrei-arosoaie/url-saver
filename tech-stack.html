Backend

Article validation
Exact absolute HTTP/HTTPS URL; reject surrounding whitespace. Required nonblank title. 400 invalid input; 413 oversized content; hash collision 500 / URL_HASH_COLLISION. Minimal accounts table supports ownership; pre-security account fixtures are automated-test-only.
Article-text preservation
Keep all article text. Remove unsafe markup without discarding prose. No silent truncation or link-only downgrade of supplied content. Test preservation.
Article title limit
Configurable 1,000 Unicode code points; reject longer titles, never truncate.
Stored article HTML
Sanitize before persistence; store sanitized HTML only. Raw HTML is not retained. OWASP Java HTML Sanitizer; preserve article structure and HTTP/HTTPS links. Remove images, scripts, forms, embeds, event handlers, inline styles and page-specific CSS classes.
Concurrent article updates
Version-based optimistic locking. JSON version starts at 0 and increments on actual changes, including enrichment. PATCH requires version; stale updates return 409, requiring reload and another explicit update. No automatic retry/overwrite.
URL uniqueness
Unique (account_id, url_hash), using application-generated SHA-256 of the exact URL. Preserve original URL in TEXT. Database CHECK verifies SHA-256 matches the exact URL. Compare full URLs on conflicts; explicit error for hash collisions, never overwrite a different URL.
Database retention & deletion
Expired-session and used-refresh-token retention durations configurable in application.yml; values and cleanup policy deferred. Account deletion and related-record deletion rules deferred.
Database record design
UUID keys throughout; article HTML in nullable articles.content TEXT; unique provider identity (issuer, subject); cursor ordering saved_at DESC, id DESC. Five-table layout confirmed: accounts, external_account_providers, sessions, refresh_tokens, articles; identity details are in the security layer.

Startup performance requirement
Under 5 seconds from application process start to save-ready, with no extra first-save initialization warm-up. Excludes Render provisioning and wake-up. Target to verify by benchmark, not a measured result.
Startup implementation rules
Use the extracted Spring Boot JAR layout; evaluate JVM AOT caching against the exact Temurin runtime. Avoid global lazy initialization; authentication and saving must be ready at startup. Minimize dependencies and initialization work. Retain Flyway, Hibernate schema validation, and required configuration validation. Include ORM initialization in startup measurements.
Startup verification
Profile bean initialization, database connection, Flyway, and Hibernate. Benchmark the production container under deployment-like CPU/memory limits and measure first-save latency. Public liveness alone does not establish save readiness. Reassess the 60-second save timeout against Render cold starts.

Phase 7 · Article connections

pgvector in Supabase PostgreSQL for semantic similarity; existing entity associations for explicit connections. Generate embeddings outside the save request. No separate vector database. Google gemini-embedding-001, called server-side from Spring Boot. Free-tier-only; no paid fallback. Gemini 429 pauses requests with a PostgreSQL-persisted cooldown, initially 24 hours and configurable in application.yml. Pending jobs survive restarts. Global Gemini concurrency starts at 1 across pods; transient retries use 1/2/4/8/16-minute delays; progress polling starts at 10 seconds. All are configurable. Reuse stored embeddings for PostgreSQL/pgvector comparisons. Phase 7 scope and architecture →

Extensible categories · Phase 2

Categories are account-owned records, not a fixed enum. Seed Architecture, Development, AI, Other, Books, Movies, TV shows and Games with their current colors. Existing articles start in Other; new accounts receive the same defaults.

Store a stable key, display name, color, default/custom origin, enabled state, creation time and version. Articles reference the same owner’s category. Filters, editing choices and node colors read this catalog.
