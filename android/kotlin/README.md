# Preserved Kotlin prototype

This directory contains the Kotlin/Jetpack Compose work started before the decision to use Capacitor: Gradle project, web-derived color tokens and logo, preview fixtures, Timeline/reader, entity views, category listing, state restoration, and model tests.

It is retained as requested. It is **not the active Android implementation** and does not have full web parity or a connected backend. Further development continues in [`../capacitor/`](../capacitor/README.md).

Existing local build outputs and ignored `local.properties` were moved along with the source. The Gradle project can be opened independently in Android Studio. No successful APK build or device verification of this prototype is claimed.
